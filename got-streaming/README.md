# 👑 משחקי הכס — ספריית צפייה אישית

פלטפורמת סטרימינג אישית ופרטית ברמת Netflix עבור סדרת "משחקי הכס", שרצה **רק על המחשב שלך** ומזרימה את הפרקים ישירות מ-Google Drive הפרטי שלך.

> React · TypeScript · Tailwind CSS · Framer Motion

---

## 🚀 הפעלה מהירה

```bash
cd got-streaming
npm install
npm run dev
```

פתח בדפדפן: **http://localhost:5173**

לבניית גרסה סופית מהירה:

```bash
npm run build
npm run preview
```

## 🎬 חיבור הפרקים — שתי דרכים

לחץ על אייקון **ההגדרות (⚙)** בפינת ה-Header. ייפתח חלון עם שני טאבים:

### 💻 תיקייה במחשב (מומלץ — פרטי, מהיר, בלי מפתח)

1. בטאב **"תיקייה במחשב"** לחץ **"בחר תיקיית פרקים"**.
2. בחר את התיקייה בכונן שמכילה את קובצי הפרקים.
3. זהו — האתר קורא את הקבצים ישירות מהדיסק, מזהה עונות ופרקים ומסדר הכול. **בלי אינטרנט, בלי מפתח, בלי שרת.**

- ב-**Chrome / Edge** האתר זוכר את התיקייה ומתחבר אליה אוטומטית בכל פתיחה.
- ב-**Firefox / Safari** תבחר את התיקייה מחדש בכל פתיחה (מגבלת הדפדפן).
- **פורמט מומלץ: MP4 (H.264)** — מתנגן בכל דפדפן. קובצי **MKV/AVI** לרוב לא מתנגנים בדפדפן; המר ל-MP4 או נגן ב-VLC.

### ☁️ Google Drive (דורש מפתח API)

1. בטאב **"Google Drive"** הדבק קישור לתיקייה ו**מפתח Google API** (מתחיל ב-`AIza` — הוראות בהמשך).
2. לחץ "התחבר וסרוק" — המערכת סורקת את התיקייה כולל תתי-תיקיות ומסדרת הכול אוטומטית.

### שמות קבצים נתמכים

המערכת מזהה את כל הדפוסים המקובלים:

| דפוס | דוגמה |
|---|---|
| `S01E01` | `Game.of.Thrones.S01E01.1080p.mkv` |
| `1x01` | `GoT 1x01.mp4` |
| עברית | `משחקי הכס עונה 1 פרק 3.mp4` |
| `Season/Episode` | `Season 2 Episode 5.mp4` |
| תיקיות עונה | תיקייה `Season 3` ובתוכה `Episode 7.mp4` או `פרק 7.mp4` |
| מספר מחובר | `301.mkv` (עונה 3 פרק 1) |

אם יש לאותו פרק כמה קבצים באיכויות שונות (`720p` / `1080p` בשם הקובץ) — יופיע בורר איכות בנגן.

### השגת מפתח API (חינם, ~2 דקות)

1. היכנס אל [console.cloud.google.com](https://console.cloud.google.com) וצור פרויקט.
2. **APIs & Services → Library** → הפעל את **Google Drive API**.
3. **APIs & Services → Credentials → Create Credentials → API Key**.
4. ודא שתיקיית הפרקים משותפת כ-**Anyone with the link** (צפייה בלבד).

המפתח נשמר **מקומית בדפדפן שלך בלבד** (localStorage) — שום מידע לא נשלח לשרת חיצוני.

## 🖼 הוספת התמונות שלך

האתר עובד גם בלי תמונות (עטיפות מעוצבות נוצרות אוטומטית), אבל כדי לקבל מראה קולנועי מלא — הנח את התמונות שלך בתיקייה `public/images/`:

```
public/images/
├── hero.jpg              ← תמונת כס הברזל לרקע הראשי (מומלץ 1920×1080+)
├── banner.jpg            ← באנר כללי
├── seasons/
│   ├── s1.jpg … s8.jpg   ← פוסטר לכל עונה (יחס 3:4)
└── episodes/
    ├── s1e1.jpg          ← עטיפה לפרק (יחס 16:9)
    ├── s1e2.jpg
    └── ...
```

התמונות נטענות אוטומטית ברגע שהן קיימות — בלי לגעת בקוד.

## ✨ תכונות

### 🎬 צפייה
- דילוג על הפתיח (Skip Intro) ועל כתוביות הסיום (Skip Credits)
- מעבר אוטומטי לפרק הבא עם **ספירה לאחור** הניתנת לביטול (או "הפעל עכשיו")
- המשך צפייה מהנקודה האחרונה — עם הצעה, או אוטומטי לגמרי (הגדרה בלוח האפקטים ❄️)
- בורר איכות (Auto + כל הקבצים שזוהו לפרק), מהירות ניגון, **סימניות** בתוך הסרטון
- **Picture-in-Picture** (`I`), **מצב קולנוע** (`C`), **מצב תיאטרון** (`T`)
- סימון "נצפה", מועדפים, **רשימת "לצפייה מאוחר יותר"**, דירוג כוכבים ותגובות (עם לייקים) לכל פרק
- דירוגי קהל (★) על כל כרטיס פרק, תגיות אוטומטיות (⚔️ קרב, 🐉 דרקונים, 💀 מוות...)

### 👤 פרופילים (למשפחה)
- **פרופילים מרובים** עם אווטאר, צבע וקוד נעילה אופציונלי (מסך פרטיות קטן, לא אבטחה אמיתית)
- **מצב ילדים** — ממשק עם כפתורים גדולים יותר
- לכל פרופיל: היסטוריית צפייה, מועדפים, רשימת צפייה, דירוגים והישגים נפרדים
- **תג משתמש** דינמי לפי כמות פרקים שנצפו ("תייר בווסטרוס" ← "מלך שבע הממלכות")

### 🏆 הישגים וסטטיסטיקות
- 12 הישגים (מהצפייה הראשונה ועד "מייסטר של הציטדל" שסיים הכול), עם התראת Toast כשנפתח הישג
- זמן צפייה כולל, אחוז השלמה עם טבעת התקדמות, **גרף פעילות** ל-14 הימים האחרונים
- **רשימות אישיות** מותאמות ("עשרת הפרקים המובילים" וכו')

### 🔍 חיפוש והמלצות
- חיפוש חי תוך כדי הקלדה: פרקים, דמויות (גם לפי שחקן), בתים, מיקומים
- **סינון מתקדם**: לפי תגית, ז'אנר, שנה ומשך פרק
- שורות בעמוד הראשי: "המשך צפייה", "חדש שנוסף", "הכי נצפה השבוע אצלך", "כי צפית ב...", "מומלץ עבורך", "הפופולריים ביותר", "ממשיך להיות פופולרי"
- כפתור **"הפתע אותי"** — פרק אקראי שעדיין לא נצפה

### 👑 עולם הסדרה
- **עמודי דמויות** — ביוגרפיה, בית, משפחה, בריתות, אויבים, הופעות וגלריה
- **עמודי בתים** — סמל, מוטו, מייסד, אזור שליטה ו**עץ משפחה אינטראקטיבי**
- **מפה אינטראקטיבית** — ערים וטירות לחיצות + שכבת קרבות מרכזיים
- **ציר זמן** של האירועים הגדולים + **כס הברזל בתלת-ממד** (גרירה לסיבוב)
- **לוח שידורים** — כל פרק לפי תאריך השידור המקורי שלו
- **גלריה** (רקעים / פוסטרים / מאחורי הקלעים / קונספט) ו**עמוד מדיה** לטריילרים וקליפים
- **חידון טריוויה** ו**מחשבון "לאיזה בית אתה שייך?"**
- ציטוט אקראי בכל כניסה

### 🛠️ ניהול הספרייה (`/manage`)
- עריכת כותרת/תקציר לכל פרק, **קאבר מותאם אישית** (העלאת תמונה), תגיות/קטגוריות אישיות
- **גיבוי וייבוא** — קובץ JSON יחיד עם כל הפרופילים, ההיסטוריה וההעדפות
- הפעלת **התראות דפדפן** כשסריקה חדשה מוצאת פרקים שלא היו קודם

### 🎨 עיצוב ואווירה
- ❄️ שלג יורד, 🔥 גיצי אש בעמוד הצפייה, ✨ סמן עכבר מותאם, 🎵 מוזיקת רקע
- **5 ערכות accent** (זהב / סטארק / לאניסטר / טארגריין / טירל) — כל האתר משנה צבע
- מצב כהה/בהיר, אנימציית פתיחה קולנועית, Parallax, Glassmorphism, טעינת תמונה עם טשטוש (blur-up)
- הכול נשלט מלוח האפקטים הצף (❄️ בפינה)

### ⚙️ טכני
- 📱 PWA — ניתן להתקנה כאפליקציה, תמיכה מלאה במגע, רספונסיבי מלא
- Lazy loading, Skeleton loading, Code splitting, Prefetch לפרק הבא, Service Worker לטעינה מהירה
- 🔒 פרטי לחלוטין: הכול רץ בדפדפן שלך (localStorage/IndexedDB), אין שרת ואין איסוף נתונים

### 🎞 מדיה אופציונלית (מוחלפת אוטומטית כשקיימת)
```
public/videos/hero.mp4          ← וידאו רקע ל-Hero
public/videos/trailer.mp4       ← טריילר (כפתור 🎬 בעמוד הראשי)
public/videos/media/*.mp4       ← טריילרים/קליפים/ראיונות/BTS לעמוד המדיה
public/audio/theme.mp3          ← מוזיקת רקע
public/images/characters/*.jpg  ← תמונות דמויות (jon-snow.jpg, jon-snow-1.jpg...)
public/images/gallery/...       ← תמונות גלריה לפי קטגוריה
```

## 🚫 מה לא נכלל — ולמה

כמה בקשות נפוצות בפלטפורמות סטרימינג **דורשות שרת אחורי ושירותי ענן חיצוניים**, מה שסותר את העיקרון המרכזי של האתר הזה: הכול רץ בדפדפן שלך, בלי שרת, בלי לשלוח נתונים לשום מקום. לכן במקומן נבנו חלופות מקומיות:

| בקשה נפוצה | למה לא | מה יש במקום |
|---|---|---|
| תקציר/תיוג/חיפוש מבוססי AI אמיתי | דורש מפתח API לשירות כמו OpenAI/Claude + אינטרנט תמידי | תיוג אוטומטי מבוסס מילות-מפתח (rule-based), רץ כולו מקומית |
| "Watch Party" עם סנכרון וצ'אט חי | דורש שרת realtime (WebSocket) לחיבור בין מכשירים | — (אפשר להוסיף בעתיד אם תרצה שרת) |
| פאנל ניהול עם "העלאת סרטונים" ו"ניהול משתמשים מרוחקים" | אין שרת שמאחסן קבצים או מנהל חשבונות מרובי-מכשירים | `/manage` — עריכת מטא-דאטה, קאברים, תגיות וגיבוי מקומי |
| Push Notifications אמיתיות (משרת) | דורש שרת Push ורישום מכשיר מול ספק (FCM/APNs) | התראות דפדפן מקומיות (Notification API) על תוכן חדש שהתגלה בסריקה |
| CDN / אופטימיזציית תמונות בענן | אין שרת להעלות אליו נכסים | Lazy loading + עטיפות SVG שנוצרות מיידית בדפדפן |
| תמיכה מלאה במספר שפות (UI מתורגם) | תרגום מלא ואמין של כל הממשק והתוכן דורש עבודה נרחבת | לא נכלל בשלב זה — האתר בעברית מלאה (RTL) |

> לשימוש אישי ופרטי בלבד, עם תוכן שבבעלותך או שברשותך הזכויות להציגו.
